# Fog of War

Локальная многопользовательская игра про танки в тумане войны для Android.

* 1–6 игроков по локальной сети (Google Play Services **Nearby Connections**, стратегия P2P star).
* Каждый видит только узкий луч фары перед своим танком; остальное скрыто туманом.
* **Два стика:** левый — езда, правый — башня и фара; отклонение стика до края стреляет.
  Кнопка огня, кнопка мины и переключатель фары — на экране.
* Раз в несколько секунд из центра карты расходится **сонар**: враги, через которых прошла волна,
  вспыхивают красными точками, а на **мини-карте** остаётся их примерное положение и волна сонара.
* Врага, попавшего в фару, ещё несколько секунд видно как затухающий красный маркер — даже когда он снова ушёл в туман.
* **Стелс:** у танка можно погасить фару; неподвижный танк без света сонар не видит, а чужие
  включённые фары видны в темноте. Выстрел выдаёт стрелка оранжевым «звуковым» кольцом.
* **Пикапы:** ремонт, усиленная пушка и мощный прожектор; **мины** — 2 заряда с перезарядкой.
* 3 HP, сужающаяся зона, 4 большие карты; в каждом новом раунде лобби — другая карта.
* Пиксель-арт спрайты, следы гусениц, взрывы, искры и тряска камеры.
* Лобби постоянное: игроки подключаются один раз и играют серию раундов без переподключения.

Подробный план и архитектура — в [AGENTS.md](AGENTS.md).

## Скачать APK

Каждый пуш в `master` собирает подписанный APK в GitHub Actions:
**Actions → Android CI → последний запуск → Artifacts → `fog-of-war-apk`**.

Самая свежая сборка также публикуется в релиз **latest**:
https://github.com/demchuckoleg-svg/fog-of-war/releases/download/latest/fog-of-war-latest.apk

APK подписан одним и тем же ключом (`keystore/release.p12`), а `versionCode` растёт с каждым
запуском CI, поэтому новая сборка ставится поверх предыдущей без удаления приложения.

> Ключ подписи лежит в репозитории намеренно — это pet-проект для установки с друзьями,
> а не публикация в Google Play. Для настоящего релиза замените keystore и задайте
> `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD` через GitHub Secrets.

## Как играть

1. Установите APK на все телефоны, включите Bluetooth и Wi-Fi.
2. Один игрок: введите ник → «Создать комнату» (он хост, выбирает карту и жмёт «Начать бой»).
   В лобби виден **код комнаты** (например, `K7Q`) — его можно назвать друзьям.
3. Остальные: «Найти игру» → экран «Комнаты рядом»: видно ник хоста, код, карту и число
   игроков в каждой комнате; тап по комнате подключает к ней.
4. После раунда все возвращаются в то же лобби; подключение сохраняется.
5. Если хост один — в бой добавятся 4 бота.

Управление в бою:

* **левый стик** — ехать (корпус плавно доворачивается);
* **правый стик** — прицеливание башни/фары: потяни и отпусти — выстрел в эту сторону, короткий тап — автоогонь по ближайшему врагу (иначе в случайную сторону);
* **кнопка с миной справа снизу** — поставить мину (заряды восстанавливаются), **лампочка справа сверху** — фара вкл/выкл.

## Сборка локально

```bash
./gradlew assembleRelease
```

Нужны JDK 17 и Android SDK 34. Локально в этом окружении SDK нет — сборка идёт в CI.

## Структура

```
app/src/main/java/com/fogofwar/game/
  core/    — чистая Kotlin-симуляция (карты, физика, зона, сонар, боты) + JVM-тесты
  net/     — Nearby Connections, бинарный протокол, дескриптор комнаты, хост/клиент раунда
  render/  — SurfaceView: камера, туман с вырезом фары, сонар, HUD, джойстик
  MainActivity.kt / RoomsActivity.kt / GameActivity.kt
keystore/  — единый ключ подписи (PKCS12)
.github/workflows/android.yml — тесты + сборка APK
```
